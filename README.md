## How I like to build

```text
understand the user → model the data → define boundaries → ship a thin slice
        ↑                                                     ↓
        └──────────── observe, simplify, and iterate ─────────┘
```

- Start with the real user journey, not a checklist of technologies.
- Keep interfaces and service boundaries explicit.
- Use AI where it reduces friction or improves a decision—not as decoration.
- Document assumptions, especially around security, data, and deployment.
- Prefer a working, inspectable slice over a very large promise.
